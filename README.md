<h1 align="center">📡 Trackly 📡</h1>
<p align="center">Trackly is a Windows desktop app that automatically or manually monitors your favorite communities for new posts in one clean feed.</p>

## 🚀 Getting Started

### ⚙️ Requirements

- Windows 10 or later
- .NET 10 or later

### 📦 Installation

1. Download the latest release from the [Releases](../../releases) page
2. Extract and run `Trackly.exe`
3. No installation required — just run and go

## 🗺️ Roadmap

### 🔜 UX
- [ ] 🕐 Auto-check on a schedule (e.g. every 30 minutes)
- [ ] 🔔 Desktop notifications for new posts
- [ ] 🌐 Click a post to open it directly in the browser
- [ ] 📤 Export feed to Excel or CSV
- [ ] 🗓️ Filter feed by date range
- [ ] 📥 Import a list of sources from a text file to add them all at once
- [ ] 📁 Group tracked sources into custom folders
- [ ] 🔇 Mute keywords — hide posts containing specific words
- [ ] ⭐ Mark posts as read / saved
- [ ] 🔁 Configurable check interval per subreddit
- [ ] 🧹 Auto-delete posts older than X days to keep the database clean
- [ ] 🧪 A/B keyword alerts — get notified only when posts match specific keywords you care about
- [ ] 🧩 Plugin system — let users write their own source connectors for any website
- [ ] 📬 Email digest — send yourself a daily or weekly summary of new posts
- [ ] 🔐 Encrypt the local database with a user-set password
- [ ] 🧵 Show full post details and comments preview inside the app without opening a browser
- [ ] ☁️ Optional cloud sync — backup and sync your sources and settings across multiple devices
- [ ] ⌨️ Keyboard shortcut configuration
- [ ] 🖥️ Command line support — run checks headlessly via CLI for automation

### 🌍 Platform Expansion
- [ ] 📘 Facebook Groups support
- [ ] 💼 LinkedIn Groups support
- [ ] 🐦 X (Twitter) list tracking
- [ ] 💬 Discord server/channel tracking
- [ ] 🎮 Steam forum tracking

### 🎨 UI & Experience
- [ ] 🌙 Dark mode
- [ ] 📌 Pin important subreddits to the top
- [ ] 🏷️ Tag and categorize your tracked sources
- [ ] 📊 Stats view — post volume over time per subreddit

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| UI Framework | C# / WinForms |
| Runtime | .NET 10 |
| Database ORM | Entity Framework Core |
| Local Storage | SQLite |
| Data Source | Reddit JSON API (no API key required) |
